Voer je Supabase-gegevens in. Dit hoef je maar één keer te doen op dit apparaat.

Supabase → Project Settings → API → Project URL

Nog geen Supabase-account?
1. Ga naar supabase.com en maak een gratis account
2. Maak een nieuw project aan, kies regio West EU (Ireland)
3. Ga naar SQL Editor en voer de setup-SQL uit (zie bijgeleverde gids)
4. Kopieer URL en anon key hierboven
